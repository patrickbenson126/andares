Andares (wandering)

with Pat

My friend, thank you for being here. Andares means wandering, and that's all this is. I've been a map guy for so long. Now getting lost, in a place, an emotion, an experience, is the work. This is a mashup of those worlds: letting go of the path (whatever that is), still noticing all the beauty and vibrancy around me, and sharing it with you! ¿Vamos?
